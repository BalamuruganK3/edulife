# EduLife – Student Support and Learning Management Platform

EduLife is a comprehensive **student support and learning management platform** designed to help students manage academics, learning resources, communication, and personal development in a single digital ecosystem. The platform aims to improve the student experience by providing organized access to educational content, announcements, schedules, and support services.

## Overview

Students often struggle with scattered academic resources, missed announcements, and difficulty managing coursework and personal development activities. EduLife brings these essential services together into a centralized platform that is simple, responsive, and accessible.

The project focuses on **productivity, academic organization, and student engagement**, making it useful for schools, colleges, and educational institutions.

## Key features

* Student dashboard
* Course and learning resource management
* Academic announcements
* Timetable and schedule tracking
* Assignment and task management
* Attendance and academic updates
* Student profile management
* Responsive web interface
* Centralized educational resource access

## System workflow

1. User logs into the EduLife platform.
2. Dashboard displays academic information and updates.
3. Students can access learning resources and course materials.
4. Announcements and schedules are synchronized centrally.
5. Users manage assignments, attendance, and academic activities from one interface.

## Installation

### Clone the repository

```bash
git clone https://github.com/BalamuruganK3/edulife.git
cd edulife
```

### Run locally

Open the main application file:

```text
index.html
```

Or run a local development server.

### Using VS Code

1. Install the **Live Server** extension.
2. Open the project folder.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
